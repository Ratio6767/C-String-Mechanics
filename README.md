C-String-Mechanics
A technical exploration of string manipulation and text processing algorithms in C.

📂 Included Files
pig_latin_translator.c: Handles word tokenization and Pig Latin transformation.

case_insensitive_search.c: Implements a case-insensitive occurrence counter within text blocks.

🚀 How to Run
VS Code
Open the terminal (Ctrl + ~).

Compile and run:
gcc filename.c -o output
./output



CodeBlocks:
Open the .c file.

Press F9 to Build and Run.
